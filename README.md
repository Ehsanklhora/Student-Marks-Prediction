
# Student Marks Prediction

## Project Overview
This is a beginner Machine Learning project that predicts
student marks based on the number of study hours.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Models
1. Linear Regression
2. Decision Tree Regression

## Project Workflow
1. Create the dataset.
2. Split data into training and testing sets.
3. Train both machine learning models.
4. Evaluate models using MAE and R2 Score.
5. Predict marks for new students.
6. Visualize the results.

## Dataset
The project uses a small sample dataset of 10 records.
Study hours are used as input and marks as the target.

## How to Run
Install the required libraries:

pip install -r requirements.txt

Then run:

python student_marks_prediction.py

## Important Note
This is an educational project with a very small sample dataset.
Its results should not be treated as a reliable real-world prediction.
